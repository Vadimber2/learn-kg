# learn.kg — тренажёр кыргызского языка

## Русский

**learn.kg** — онлайн-тренажёр кыргызского языка для тех, кто говорит по-русски,
по-английски или по-турецки. Работает на [learn.kg](https://learn.kg).

### Что внутри

- **Курсы A1, A2, B1, B2** — по 12 модулей: десять тематических, неделя повторения
  и итоговая проверка курса.
- **Карточки с интервальным повторением** — слово, перевод, озвучка носителем
  языка, ввод ответа с клавиатуры.
- **Диалоги** с озвучкой персонажей, песни и караоке.
- **Аудиоуроки** — объяснение на языке ученика с кыргызскими примерами и слайдами.
- **Аудирование** — слушай, повтори вслух, получи оценку произношения.
- **Справочник** по грамматике каждого модуля, мини-тесты, итоговая проверка.
- **Кабинет преподавателя** — журнал занятий, прогресс учеников, сообщения.
- Публичные страницы: витрина, тест уровня, пробные тесты, разговорник,
  переводчик фраз курса, блог — на русском, английском и турецком.

> Задания составлены learn.kg по материалам курса. Они не являются заданиями
> государственного тестирования по кыргызскому языку и не связаны с ними.

### Как устроено

- **Node.js 22, без зависимостей** — ни одного npm-пакета.
- `app/src/*` — части одностраничного тренажёра; сборщик `server/appshell.js`
  склеивает их в одну страницу в порядке `app/src/manifest.json`. Данные модулей —
  `app/src/data/`, справочные страницы — `app/src/render/`.
- `server/` — HTTP-сервер, публичные страницы (`site.js`), чат, бэкапы.
- `deploy/` — генерация озвучки (ElevenLabs `eleven_v3`, кыргызский),
  реестр голосов `voices.json`, аудит аудио, скрипт деплоя.
- `tests/` — 60 сьютов, прямые проверки поведения (HTTP-ответы, исполнение
  собранного кода в `vm`).
- `CLAUDE.md` — правила проекта.

### Запуск локально

```bash
cp server/users.example.json server/users.json   # поменяйте пароль
PORT=8080 DATA_DIR=./data node server/server.js
```

Откройте http://localhost:8080. Прогресс и аудио хранятся в `DATA_DIR`.
Пароль можно сразу записать хэшем: `node deploy/hash-password.js`.

Озвучка и распознавание речи работают, если задан ключ `ELEVENLABS_API_KEY`;
без него тренажёр открывается, но новые аудио не генерируются.

В Docker:

```bash
docker build -t learn-kg .
docker run -p 8080:80 -v "$PWD/data:/data" learn-kg
```

### Тесты

```bash
npm test
npm test 2>&1 | grep -c ': OK'   # ожидается 60
```

## Кыргызча

**learn.kg** — орусча, англисче же түркчө сүйлөгөндөр үчүн кыргыз тилин
үйрөнүүчү онлайн тренажёр. Сайт: [learn.kg](https://learn.kg).

### Эмнелер бар

- **A1, A2, B1, B2 курстары** — ар биринде 12 модуль: он тематикалык модуль,
  кайталоо жумасы жана курстун жыйынтык текшерүүсү.
- **Аралыктуу кайталоо менен карточкалар** — сөз, котормо, эне тилдүү
  адамдын үнү, жоопту клавиатура менен жазуу.
- **Диалогдор** каармандардын үнү менен, ырлар жана караоке.
- **Аудиосабактар** — окуучунун тилинде түшүндүрмө, кыргызча мисалдар жана слайддар.
- **Угуу** — угуп, үн чыгарып кайталап, айтылыштын баасын алуу.
- Ар бир модулдун грамматикасы боюнча **маалымдама**, мини-тесттер, жыйынтык текшерүү.
- **Мугалимдин кабинети** — сабактардын журналы, окуучулардын жетишкендиги, билдирүүлөр.
- Ачык барактар: башкы бет, деңгээл тести, сынамык тесттер, сүйлөшмө,
  курстагы фразалардын котормочусу, блог — орус, англис жана түрк тилдеринде.

> Тапшырмаларды learn.kg курстун материалдары боюнча түзгөн. Алар кыргыз тили
> боюнча мамлекеттик тестирлөөнүн тапшырмалары эмес жана алар менен байланышы жок.

### Кантип түзүлгөн

- **Node.js 22, көз карандылыктар жок** — бир да npm-пакет колдонулбайт.
- `app/src/*` — тренажёрдун бөлүктөрү; `server/appshell.js` аларды
  `app/src/manifest.json` тартиби боюнча бир баракка чогултат. Модулдардын
  маалыматтары — `app/src/data/`, маалымдама барактары — `app/src/render/`.
- `server/` — HTTP-сервер, ачык барактар (`site.js`), чат, камдык көчүрмөлөр.
- `deploy/` — үн жаратуу (ElevenLabs `eleven_v3`, кыргызча), үндөрдүн реестри
  `voices.json`, аудио текшерүү, деплой скрипти.
- `tests/` — 60 тест топтому: жоруктун түз текшерүүлөрү (HTTP-жооптор,
  чогултулган коддун `vm` ичинде аткарылышы).
- `CLAUDE.md` — долбоордун эрежелери.

### Компьютерде иштетүү

```bash
cp server/users.example.json server/users.json   # сырсөздү алмаштырыңыз
PORT=8080 DATA_DIR=./data node server/server.js
```

http://localhost:8080 дарегин ачыңыз. Прогресс жана аудио `DATA_DIR` ичинде сакталат.
Сырсөздү хэш түрүндө жазса болот: `node deploy/hash-password.js`.

Үн жаратуу жана кепти таануу `ELEVENLABS_API_KEY` ачкычы берилгенде иштейт;
ачкычсыз тренажёр ачылат, бирок жаңы аудио жаратылбайт.

Docker менен:

```bash
docker build -t learn-kg .
docker run -p 8080:80 -v "$PWD/data:/data" learn-kg
```
