# Формат скрипта урока и все гейты

Файл: `deploy/lesson-<mod>-script.json` (урок m0 исторически —
`pronunciation-script.json`). Это единственный источник и для транскрипта на
экране, и для текста озвучки.

## Содержание
- Скелет скрипта урока
- Гейты `tests/pronunciation.test.js`: контракт файла, треки, сегменты, вычитка, пруфы
- Гейты `tests/lessons.test.js`: реестр, плеер, слайды, SVG-набор, вариантная гигиена, mp4-план

## Скелет

{
  "updated": "2026-08-20",
  "note": "Правила генерации: каждый сегмент своим запросом со своим language_code…",
  "voiceRole": "female_adult",
  "lesson": {
    "mod": "m1",
    "id": "self-intro",
    "title": { "ru": "Урок 2. О себе: …", "en": "Lesson 2. …", "tr": "Ders 2. …" },
    "intro": { "ru": "Шесть тем: …", "en": "Six topics: …", "tr": "Altı konu: …" }
  },
  "tracks": [
    {
      "id": "m1t1",
      "title": { "ru": "Местоимения: мен, сен, сиз…", "en": "…", "tr": "…" },
      "segments": [
        { "kind": "explain", "text": { "ru": "…", "en": "…", "tr": "…" } },
        { "kind": "example", "ky": "Мен. Сен. Сиз. Ал.",
          "gloss": { "ru": "я · ты · Вы · он/она", "en": "…", "tr": "…" },
          "gap": true }
      ],
      "refs": [
        { "claim": "У кыргызского восемь личных местоимений…",
          "src": "en.wikipedia.org/wiki/Kyrgyz_language, раздел Pronouns (проверено 20.08.2026)",

      ]

## Гейты `tests/pronunciation.test.js` (перебором всех скриптов реестра)

Контракт файла:
- `updated` — дата `YYYY-MM-DD`; `voiceRole` обязан быть ключом `deploy/voices.json`.
- `lesson.mod` совпадает с ключом в `LESSON_SCRIPTS`; `lesson.id` — `^[a-z0-9-]{3,24}$`
  (он же слаг файлов видео и `LESSONS.<mod>.id`).
- `lesson.title[l].length > 4` и `lesson.intro[l].length > 10` для ru/en/tr.

Треки:
- `id` — `^[a-z0-9]{1,12}$`, **глобально уникален** между уроками (аудио всех
  уроков живёт в одном бакете m0: `ph_<тема>_<NN>`).
- `title` на трёх языках, длиннее 4 символов; сегментов ≥2.
- В треке обязаны быть и `explain`, и `example`; хотя бы один пример — фраза
  из ≥3 слов (звук/правило показывается и словами, и в связной речи).
- Последний сегмент трека — `"gap": true` (пауза перед следующей темой).
- `kind` — только `explain` или `example`; текст объяснения длиннее 2 знаков.
- **В уроке обязан быть сегмент `repeat`, и он не может быть первым**
  (lessons.test ищет `findIndex(s => s.repeat) > 0`). `gap` и `repeat` на одном
  сегменте несовместимы: плеер проверяет `gap` раньше, и пауза на повтор просто
  не наступит — практику держи внутри темы, а `gap` оставь её последнему сегменту.

Сегмент `explain` (озвучивается ×3 языка, id `ph_<тема>_<NN>_<lang>`):
- Текст на ru/en/tr, каждый ≤480 знаков (серверная ручка режет на 500).
- **Ни одной буквы ң/ө/ү** — модель прочтёт их фонетикой языка дорожки.
- Только алфавит своего языка: в ru — кириллица, в en — ASCII, в tr — турецкий
  набор. Кириллица в en/tr = тарабарщина у диктора.
- Запрещены имена чужих языков и их диакритик (`немецк|французск|турецк|…`,
  `French|German|Arabic|Spanish|Turkish|Russian|umlaut`, `Fransızca|Almanca|…`).
  Свой язык и кыргызский — можно.
- В en запрещены `sing|song|singing`: диктор произносит «г», которого в ң нет.
- Поле `say` недопустимо.

Сегмент `example` (одна кыргызская дорожка на все языки, id `ph_<тема>_<NN>`):
- `ky` непустой + `gloss` на трёх языках.
- Необязательные: `speed` (практика — 0.7), `repeat: true` (плеер держит паузу
  1,2–4 с и пишет «Ваша очередь»), `gap`.
- `say` — орфоэпическая запись ТОЛЬКО для TTS: кириллица, ≤300 знаков, ≠ `ky`.

Вычитка кыргызского (главный гейт): каждое высказывание, разрезанное по
`[.!?,;]`, обязано быть либо фразой курса дословно, либо словом курса, либо
записью в `LESSON_DEMOS` (tests/pronunciation.test.js) с обоснованием.
Разрез по запятой — частая ловушка: «Ооба, мен мугалиммин» → «ооба» +
«мен мугалиммин», и хвост нужно занести в белый список отдельно.

Пруфы:
- `refs` ≥1 у каждого трека; `claim` ≥15 символов, `src` ≥10.
- `quote` (если есть) ≥15 символов и **дословна** — сверяй с сохранённой копией
  источника, а не по памяти.
- Хотя бы у одного ref трека есть `quote`, иначе все `src` обязаны быть
  эмпирикой курса (`эмпирика…` / `tests/…`) — то есть проверяемыми тестом.

## Гейты `tests/lessons.test.js`

- Реестр `LESSONS.<mod>` обязан 1:1 совпадать с компиляцией скрипта (иначе —
  `node deploy/gen-lessons.js`); порядок тем, id, `voiceRole`, титулы.
- Плеер прогоняется в vm **по каждому уроку**: автопереход, отметка темы,
  пауза `repeat` в границах 1,2–4 с, текст/скорость, возврат на место, края
  очереди, событие `lesson.theme` в журнал.
- Слайд обязан быть у **каждой** темы каждого урока; файл `app/lessons/<img>.webp`
  существует; `items` — минимум один; кыргызские слова слайда — слова скрипта
  своего урока (плюс белый список `ORTHOEPIC`); русский глосс подписи встречается
  в скрипте; подписи на трёх языках.
- `top`: регексп гейта — `/^[а-яёөүң ]+$/`, ≤8 знаков. То есть **строчные**
  кириллические буквы и пробел; заглавная «Ө» тест не пройдёт.
- «Языковые версии различаются» проверяется только парами ru≠en и ru≠tr —
  одинаковые en и tr гейт пропустит, следи сам.
- SVG-набор `LESSON_FIGS` — запасной: покрывает урок либо целиком, либо никак;
  сверх того гейт держит геометрию (viewBox 16:9, ≥5 штрихов, только команды
  пути, палитра мела, толщина 2–8, координаты внутри доски) и исполняет
  отрисовку (два прохода на штрих, `null` для темы без рисунка).
- Вариантная гигиена: `LESSONS.m1` и его слайды едут только в сборки с m1.
- Ключи `LESSONS` в точности равны ключам `LESSON_SCRIPTS` — лишний урок в
  реестре или потерянный скрипт валит тест.
- Интерфейсные ключи раздела (`tab_lessons`, `lesson_play`, `lesson_text_hidden`,
  `lesson_themes`, `lesson_next`, `lesson_repeat_now`) обязаны быть ровно
  в трёх языках.
- Отдельный гейт — **план mp4-экспорта** (`planFor` из deploy/make-video.js):
  число тем, точное совпадение id дорожек с сегментами урока, существование
  `.webp`, отсутствие `undefined` в строках панели. Сейчас сверяется для m0.
- Общий нормализатор обоих гейтов — `tests/helpers/lesson-script.js`
  (`norm`, `exampleWords`): правило «слова слайда = слова скрипта» опирается на него.
