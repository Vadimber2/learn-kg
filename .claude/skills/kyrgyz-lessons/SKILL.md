# Аудиоуроки learn.kg: создание и выпуск

Выучено на уроках 1 (произношение, m0) и 2 (о себе, m1). Каждое правило — реальный
промах или прямое требование владельца.

## Железные правила (нарушение = брак или красный гейт)

1. **Каждое утверждение урока — с подтверждением и citation** (владелец, 20.08.2026):
   блок `refs` трека хранит `claim` + `src` + **дословную** `quote`. Гейт требует
   ≥1 ref на трек и хотя бы одну цитату (либо все refs — «эмпирика курса»);
   кросс-валидация вторым источником — практика для спорных утверждений, а не
   проверка машиной. Проверенные источники грамматики — `references/sources.md`.
2. **Кыргызские примеры — только дословно из вычитанного курса** (vocab модулей)
   либо белый список `LESSON_DEMOS` в pronunciation.test.js с обоснованием.
   Сочинять кыргызский нельзя («миң рахмат» — калька, поймал носитель).
   Внимание: валидатор режет по `[.!?,;]` — «Ооба, мен мугалиммин» распадается
   на «ооба» + «мен мугалиммин», хвост нужен в белом списке.
3. **Ориентир — только из языка дорожки**: букв ң/ө/ү нет ни в одном объяснении
   (гейт применяется ко всем трём языкам), в en/tr — ни одной кириллицы, чужие
   языки как опора запрещены; звук показывает кыргызский голос отдельным
   сегментом. Полные правила текста — `references/script-format.md`.
4. **Один источник для экрана и наушников**: транскрипт и озвучка собираются из
   одного скрипта; правки — только в скрипт + перегенерация.
5. **Порядок выпуска**: аудиоурок без видео → владелец оценивает → видео только
   после (или по явному приказу владельца).
6. **После генерации — аудит затухания до 0 подозрительных**, эскалация:
   1–2 дубля → Robust (STABILITY=1) → орфоэпия. Аудит с авторизацией.
7. **Темп задаёт ученик, а не таймер** (владелец, 21.08.2026): у плеера есть тумблер
   «Автопродолжение» и кнопка «↻ Повторить». Выключенное автопродолжение
   останавливает урок после КАЖДОГО сегмента (включая практику с `repeat` — там
   таймерная пауза не заводится вовсе), и ученик слушает фразу столько раз, сколько
   нужно. Кыргызская фраза короткая: на паузу вовремя не нажать, а на следующем
   сегменте повторять уже нечего. Режим хранится в снимке урока (`auto`) вместе
   с местом, текстом и скоростью; гейт — `tests/lessons.test.js`, перебором уроков.

## Как сделать новый урок (порядок)

Скопируй в ответ и отмечай по ходу:

```
Урок <mod>:
- [ ] 1. Скрипт deploy/lesson-<mod>-script.json (+ refs с цитатами)
- [ ] 2. Строка в LESSON_SCRIPTS + node deploy/gen-lessons.js
- [ ] 3. Части lessons/<mod>.js и <mod>-slides.js в manifest.json
- [ ] 4. Слайды тем (рисунки без текста) + просмотр глазами
- [ ] 5. check-script.js чист → npm test зелёный
- [ ] 6. Озвучка PROD=1 → аудит затухания = 0 → деплой
- [ ] 7. Оценка владельца → только потом видео
```

1. **Скрипт** `deploy/lesson-<mod>-script.json` — формат и все гейты полей:
   `references/script-format.md`. Темы: id `<mod>t<n>` (глобально уникальны —
   бакет аудио общий), последний сегмент темы `gap:true`, практика —
   `repeat:true` + `speed:0.7`, у каждой темы пример-фраза ≥3 слов.
2. **Реестр**: строка в `LESSON_SCRIPTS` (deploy/gen-lessons.js) — его читают
   генераторы озвучки/видео и оба гейта. `node deploy/gen-lessons.js` →
   для M1+ создаёт часть `app/src/data/lessons/<mod>.js` (едет только своим).
3. **Слайды**: рисунки OpenAI «мел на доске» СТРОГО БЕЗ ТЕКСТА →
   `app/lessons/<тема>.webp`; слова панелей — только слова скрипта, глоссы
   дословно из него; часть `app/src/data/lessons/<mod>-slides.js` + строка
   в manifest.json. Детали и промпт-стиль: `references/pipeline.md`.
4. **Тесты**: `npm test` — lessons.test и pronunciation.test перебирают все
   уроки сами; сверить ЧИСЛО зелёных сьютов с ожидаемым, докер-прогон перед PR.
5. **Озвучка на прод**: `KGA1_AUTH=… PROD=1 KGA1_LESSON=<mod>
   node deploy/gen-pronunciation.js` (бакет m0, ph_<тема>_NN; объяснения ×3 языка).
   Затем аудит и эскалация (правило 6). Публичный снимок ph_* пересобирается
   только рестартом → деплой после генерации.
6. **Деплой по ритуалу проекта** (докер, смоук), проверить вкладку «Уроки»
   модуля на проде.
7. **Видео (после оценки владельцем)**: полный ролик ×3 языка + шортс на тему
   ×3 языка, заставка из lesson.title, карточка «Видео» фильтрует по слагу
   урока. Команды и грабли: `references/pipeline.md`.

## Цикл проверки (валидатор → починил → повторил)

Перед генерацией озвучки **запусти** валидатор скрипта — он проверяет те же
правила, что и гейт, но за секунду и без сборки приложения:

```bash
node ${CLAUDE_SKILL_DIR}/scripts/check-script.js deploy/lesson-<mod>-script.json
```
Ненулевой код возврата = список нарушений. Чини и запускай снова, пока не
станет чисто; только после этого — `npm test` и генерация. Смысл цикла в том,
что ошибка в тексте, найденная после генерации, уже оплачена символами.

## Слайды и иллюстрации уроков (перенесено из CLAUDE.md 22.08.2026)

Основной слайд темы — **гибрид** (`app/src/data/lesson-slides.js` + `app/lessons/*.webp`):
рисунок генерирует OpenAI («мел на доске») **строго без текста** — модель врёт
в буквах (ң рисовала сербской Ћ, «көл» писала «кол»); буквы и слова кладёт клиент
настоящим текстом панелями над и под рисунком (`lessonSlide`). Так буквы верные,
текст доступен скринридеру, а глоссы по языку интерфейса дают один слайд на ru/en/tr.

- Кыргызские слова слайда обязаны быть словами скрипта озвучки, глоссы — дословно
  из него; гейт в `tests/lessons.test.js` валит сочинённые (проверен подставным словом).
- Файлы раздаются публично на `/lessons/…` (урок открыт анониму в демо), демо-артефакт
  получает срез реестра из сборки. У `img` aspect-ratio 3/2 — без него панели слипаются
  до lazy-загрузки.
- Запасной вариант тем без слайда — рисованные inline-SVG (`lesson-figs.js`, рисует
  `lessonFig` DOM-методами, ноль внешних запросов); тема без рисунка возвращает null
  и урок не падает.
- Доска тёмная в любой теме; в тёмной слайд притеняется фильтром
  (`brightness(.88) contrast(1.04)`) — осветление превратило бы доску в лист бумаги.
- Скрины настоящего экзамена в «Обзоре» модуля — поле `shots` контента
  (img/cap ×3 + `shotsHdr`/`shotsIntro`/`shotsSrc`), файлы там же в `app/lessons/`.
