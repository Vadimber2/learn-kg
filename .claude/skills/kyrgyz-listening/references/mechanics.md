# Аудирование: механика, доступ, добавление блока

## Новый блок дрилла (например, согласные или стыки слов)

1. Запись в `STT_BLOCKS` (`app/src/data/stt-blocks.js`):
   ```js
   { id: "<короткий id>", kind: "sounds", items: [ { ch: "<буква>", m: ["<подстроки>"],
     m2: ["<долгая пара>"], hint: "<ключ подсказки>", d: "…", dEn: "…", dTr: "…" } ] }
   ```
   `m`/`m2` — подстроки поиска слов в пуле (например, «е» и «э» — один звук;
   долгий гласный — сдвоенная буква). Слова подбираются из словаря варианта
   ученика автоматически, поэтому пул растёт вместе с модулями.
2. Титул блока `stt_b_<id>` в словарях всех трёх языков (гейт ищет ровно три
   вхождения).
3. Больше ничего: рендерер `kind:"sounds"` общий, слова «долгий» он не знает —
   об этом говорит только `hint`.

**Требования к описаниям звука (гейт `tests/stt.test.js`, применяется ко всем
items любого sounds-блока, а не только к гласным):**
- `d`, `dEn`, `dTr` — строки **длиннее 20 знаков**, заглушки не проходят.
- Канон «локализация, а не калька»: в `dEn` запрещено слово `russian`,
  в `dTr` — `rusça`/`rus dili`, в `d` — «английск/немецк/французск/турецк».
  Каждый язык объясняет звук своими ориентирами.
- Если у элемента есть `m2` (второй набор написаний), у него **обязан** быть `hint`.
- Реестр обязан объявляться и в демо-артефакте: `renderListen` ссылается на него
  вне DATA-региона, иначе демо падает.

Блок `kind:"queue"` («Фразы дня») в реестре один: его наполняет очередь SRS,
отдельного списка у него нет. **Он обязан оставаться первым** — гейт пиннит
`BLOCKS[0].id === "phrases"` как блок по умолчанию, новые записи добавляются
после него.

Вводные строки дрилла (`stt_v_intro`, `stt_v_words`) общие для всех
sounds-блоков: свой текст именно для нового блока потребует правки логики,
то есть выхода за «ноль правок» — решать осознанно.

## Очередь дня (`sttQueue`)

```
пул = не-alias фразы с текстом и озвучкой (alias тренируется у донора)
приоритет 1: фразы, у которых подошёл срок SRS-повторения
приоритет 2: остальные
внутри группы: от коротких к длинным; равные разводит стабильный сид от даты
```
Отсюда свойство «набор стабилен внутри дня»: перезагрузка страницы не тасует
упражнения, а дневной лимит совпадает с дневным набором.

## Скоринг

- Ответ Scribe нормализуется и сверяется **пословно** с эталоном; доля
  совпавших слов = балл попытки.
- Личный лучший результат по фразе хранится в прогрессе (`ST.stt`) и переживает
  сессию; строка балла показывает лучший только если он выше текущего.
- Секунды для учёта затрат берутся из таймингов слов ответа, а не из длины
  файла — так считается фактически распознанное время.

## Доступ и лимиты

| Кто | Что |
|---|---|
| Ученик с постоянным курсом | по флагу `stt` в `students.json`; лимит `sttLimit` (дефолт 20/день, допустимо 1..500) |
| Чисто триальный ученик | опция недоступна |
| Преподаватель/админ | безлимитно |
| Аноним (демо) | вкладки нет; реестр в демо-срезе есть как справочный материал |

Смена флага/лимита — через API преподавателя (`sttLimit: null` возвращает
дефолт). Роль teacher не принимает поля ученика (курсы, триалы, stt) —
сервер отвечает 400.

## Серверная ручка

`POST /api/stt/<mod>`: принимает аудио, ходит в `ELEVEN_STT_URL`
(по умолчанию `https://api.elevenlabs.io/v1/speech-to-text`), пишет запись в
`/data/stt-usage.json`. В тестах внешний вызов **мокается** переменной
окружения `ELEVEN_STT_URL` — реальный ключ прогону не нужен, и это правило:
новые тесты не должны требовать сетевого доступа к ElevenLabs.

Порядок проверок сервера: доступ → лимит → внешний вызов. Тест стережёт, что
при закрытом доступе или исчерпанном лимите запрос **до внешнего STT не доходит**
(иначе платная квота тратилась бы на отказ).

## Хоткеи

Пробел — говорить, модификатор+Пробел — слушать, → — дальше (`sttHotkey`
работает по физическим кодам клавиш, поэтому раскладка не важна).

## Гейты `tests/stt.test.js`

Перебором состояний: выключено / триал / включено / лимит исчерпан; плюс
учёт затрат в файле и в карточке ученика, отсутствие вкладки в демо,
vm-сверка пословного сравнения, блоки и дрилл гласных, кнопка на карточке и
строка балла.
