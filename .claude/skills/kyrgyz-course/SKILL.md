# Модули и курсы learn.kg: как заводить

Курс = **12 модулей**: 10 контентных + модуль повторения (без новых слов) +
экзаменационная неделя (`exam:true`). Так устроены A1 (m0–m11), A2 (m12–m23),
B1 (m24–m35); id модулей сквозные — следующий курс продолжает нумерацию за
последним модулем в `MODULE_META`.

**Главный принцип: новый модуль = данные в реестры, ноль правок логики и
маршрутов.** Если для модуля понадобилась ветка в коде — механизм недообобщён,
чини механизм. Пропуск любого реестра ловят гейты, но время экономит чеклист.

## Меню модуля и «Обзор» — одно целое

**Правило владельца 21.08.2026.** Появился или исчез раздел модуля (Уроки,
Аудирование, Видео) — план недели в «Обзоре» ЭТОГО модуля правится в том же PR.
План живёт в `app/src/data/content/m<n>.js`: `plan` / `planEn` / `planTr`, и раздел
называется там ровно так, как он подписан во вкладке (`tab_lessons`, `tab_listen`).

Иначе ученик открывает вкладку, которой нет в плане, — или ищет по плану раздел,
которого у него нет: «Обзор» это единственный экран, который говорит, что делать
по дням. Гейт — `tests/ui-generic.test.js`: перебором модулей с уроком (`LESSONS`)
и с аудированием (`STT_MODS`) проверяет, что раздел назван в плане на всех трёх
языках, и что модуль БЕЗ урока не обещает вкладку «Уроки».

## Новый модуль (в существующий курс)

Пошагово, с точными именами файлов и тем, что упадёт при пропуске —
`references/module-checklist.md`. Коротко:
1. Данные: `app/src/data/m<n>.js` (`CATS_M<n>`/`VOCAB_M<n>`/`DRILL_M<n>`) и
   **обязательный** `app/src/data/content/m<n>.js` (там модуль вписывается в
   `CONTENT` вместе с `catsEn`/`catsTr`); диалоги
   `app/src/data/dialogs/m<n>.js` — по наличию. Не забыть **запятую** в конце
   предыдущего фрагмента: части склеиваются в один литерал.
2. Реестры: `CONTENT_READY`, `MODULE_META` (+`course`, титулы EN/TR),
   `MODULE_EXTRAS`, `COURSES.<курс>.modules` в server.js.
3. Рендерер: `app/src/render/NNN-render*M<n>.js` + строка в `app/src/manifest.json`
   (файл вне манифеста роняет старт; тело функции обязано иметь сигнатуру `(m)`).
4. Ручные подписи в тестах: эталон `CONTENT_READY`, `REVISION_MODS` (для
   повторительного **и** экзаменационного), для B1+ — `B1_MODS` и конкатенация
   `M<n>_REFS`.

## Новый курс (B2 / C1 / C2)

Полный чеклист — `references/course-checklist.md`. Ключевое:
- **Сначала план, потом контент**: темы уровня — решение владельца (наш учебный план
  по шкале CEFR). Материалы официального тестирования не копируются и не цитируются,
  название учреждения не упоминается (решение 30.10.2026, см. CLAUDE.md «Экзамен курса»).
- Курс трогает: `COURSES`, `app/kurs/kurs.json`, карточку витрины и её итоговые
  цифры, футер (`siteFooter` в `server/site.js` — **не** `SITE_NAV`),
  `app/help/help.json`, `app/seo-lastmod.json`, `deploy/seo-keywords.json`,
  разметку курсов и **полтора десятка мест, где список курсов зашит руками
  в тестах**. Полный разбор — в чеклисте.
- Витрина держит неоткрытый уровень карточкой «Скоро»; открытие уровня ломает
  жёсткое «три чипа Скоро» в landing.test — это ожидаемый красный, не сюрприз.

## Состояние реестров и цикл проверки

Актуальные числа не зашиты в текст — **запусти** и получи их:

```bash
node ${CLAUDE_SKILL_DIR}/scripts/state.js
```
Печатает состав курсов, следующий свободный id модуля, ожидаемое число зелёных
сьютов и модули вне реестра готовности.

Цикл выпуска: `npm test` → починил → снова `npm test`, пока не сойдётся **число**
зелёных сьютов (не exit-код), затем докер-прогон на образе прода. Тесты здесь
и есть валидатор: красный на новом модуле — норма, он показывает пропущенный шаг.

## Правила контента (обязательны для обоих сценариев)

Подробно — `references/content-rules.md`. Самое дорогое:
- **≥85 своих единиц** в модуле (m0–m3 — ≥90), дриллов ≥10; модуль повторения —
  ровно 0 новых слов и запись в `REVISION_MODS`.
- Фраза, уже введённая в другом модуле, обязана быть alias `{ref:"…"}` — иначе
  ломается единый прогресс слова; донор обязан идти раньше по `CONTENT_READY`.
- Поле `ky` — чистый текст без пометок (его читает TTS и сверяет ввод), пометки
  живут в переводных глоссах; `catsTr` по ключам совпадает с `cats`; у каждой
  фразы есть `tr`.
- B1 и выше: формулировки дриллов на кыргызском (`qKy` + перевод по клику),
  каждое своё слово вводится кыргызской дефиницией `def`, незнакомых токенов
  ≤20% и каждый — в `DEF_GLOSS_M<n>` с ru/en/tr.
- Цена нигде не упоминается (тест стережёт).

## Выпуск

Озвучка нового модуля — `deploy/gen-audio.js <mod>` (реплики и куплеты всех
модулей живут в бакете m0, генерируются прогоном `m0`), затем **аудит затухания
обязателен**; голоса персонажей — реестр `deploy/voices.json` (скилл `kyrgyz-tts`).
Дальше — общий ритуал: `npm test` со сверкой числа зелёных сьютов, докер-прогон,
бамп версии, PR, деплой.

## Курс B1 (m24+): свои правила (перенесено из CLAUDE.md 22.08.2026)

Экзамен и пробные тесты — наши материалы, не официальные (CLAUDE.md «Экзамен курса»).

- Тема модуля — тема нашего плана; ссылок на сайт тестирования и цитат в данных нет.
- Формулировки дриллов — на кыргызском (`qKy`), перевод по клику через `drillQNode`.
- Каждое своё слово вводится кыргызской дефиницией `def` через уже выученное:
  незнакомых токенов ≤20% массы, каждый — в глоссарии `DEF_GLOSS_M<n>` (+строка
  в реестре `DEF_GLOSS`) с ru/en/tr, разбор по клику (`b1DefNode`/`b1Prompt`,
  маркер `===B1===` в 15-boot).
- Аудио B1 — естественный темп (дескриптор Угуу №10), не замедлять.
- Гейты — `tests/b1.test.js`; новый модуль B1 = строка в `B1_MODS` там же.
- **Умолчания до решения владельца о продаже**: витрина держит карточку B1 «Скоро»
  и говорит «24 модуля» (landing.test считает только продаваемые A1+A2); апселл
  следующего курса B1 не предлагает; выдача — только руками преподавателя.

## Триалы: полный формат (перенесено из CLAUDE.md 22.08.2026)

Поле `trials: {"<курс|модуль>": "YYYY-MM-DD"|null}` в students.json: доступ до даты
ВКЛЮЧИТЕЛЬНО (конец дня по Бишкеку, +06) либо без ограничения. Формат аддитивен:
у записи без поля поведение прежнее (постоянные ученики не задеты — обещание
владельца, гейт `trials.test.js`), старый сервер поле не читает.

Активный триал-курс = выданный (та же тропа); одиночный триал-модуль открыт сразу;
истёкший триал = отнятый курс (`result_only` при прогрессе, живой API закрыт).
Постоянная выдача курса гасит его триал. Ключ варианта страницы включает триалы
с датами — истечение пересобирает вариант без рестарта. UI преподавателя: меню
чипа курса + строка «Триал-модули».
