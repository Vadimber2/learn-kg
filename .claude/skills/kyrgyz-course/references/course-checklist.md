# Новый курс (B2 / C1 / C2): чеклист сверх модульного

Курсы A1/A2/B1 — образец. Витрина заранее держит B2/C1/C2 карточками «Скоро».

**Главная ловушка**: реестры данных автоматизированы и защищены гейтами, а вот
**списки курсов, зашитые руками в тестах и текстах**, — нет. Именно там живут
молчаливые пропуски: тест остаётся зелёным, а продукт врёт.

## Шаг 0. Фактура уровня (до единой строки контента)

Темы уровня — решение владельца (наш учебный план по шкале CEFR); материалы
официального тестирования не копируются, учреждение не упоминается (CLAUDE.md
«Экзамен курса»). Нет утверждённого плана — спросить, не выдумывать. Гейт уровня пишется по образцу
`tests/b1.test.js` со своим `<LVL>_MODS` — **это новый сьют**, значит число
зелёных сьютов в `CLAUDE.md` увеличивается на единицу — обнови его в том же PR.

## Шаг 1. Реестры и данные

## Шаг 2. Публичные страницы и витрина

| Что | Где | Деталь |

| Реестр SEO-ключей | `deploy/seo-keywords.json` | **без записи `/kurs-<lvl>` seo-keywords.test падает**; нужен `primary.{ru,en,tr}` с `match`, реально встречающимся в `<title>` |
| Schema | `buildGraph` (server.js) | `Course` с `@id` + позиция в `ItemList`; счётчик курсов в server.test (`courses.length === 3`) — обновить |
| Итоговые цифры витрины | `app/landing.html` | «36 модулей», «2789 фраз», «Открыты уровни A1, A2 и B1» — ~8 ключей × 3 языка, меняются руками |
| Блерб llms.txt | `server/server.js` | список страниц строится из реестра, но диапазон «A1–B1» в тексте зашит |

## Шаг 3. Захардкоженные списки курсов в тестах (иначе — зелёный и врущий)

## Шаг 4. Доступ, тропа, деньги

- Выдача курса и триалы — рантайм-данные тома (`students.json` в `/data`,
  правится панелью преподавателя, а не PR); формат курс-агностичен.
- Тропа считается по каждому выданному курсу отдельно; отнятый курс остаётся
  видимым как результаты.
- Перебор комбинаций курсов — `tests/trail.test.js` (плюс наборы сборки в
  `tests/appshell.test.js`).

## Шаг 5. Публичные разделы, которые НЕ подхватят курс сами

- `app/razgovornik/razgovornik.json` — секции перечисляют модули руками
  (на момент написания — часть A1/A2, B1 туда не попал); гейт держит лишь
  коридор по числу фраз, покрытия новых модулей он не требует.
- Блог и SEO-планы: открытие уровня — инфоповод (по требованиям госслужбы
  B2 с 2027, педагоги и медики B2 с 2028 — см. `docs/seo-facts-and-sources.md`).

## Шаг 6. Выпуск

Обычный ритуал (тесты со сверкой числа сьютов → докер → бамп версии → PR →
деплой) + правка `CLAUDE.md` (число сьютов, блок правил уровня, если он свой)
+ SEO-хвост: три новых URL в обе системы (IndexNow, Вебмастер, ручной Request
indexing в Google) и запись в `docs/seo-facts-and-sources.md`.
