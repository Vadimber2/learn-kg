# Кыргызская озвучка через ElevenLabs (learn.kg)

## Проверенный рецепт генерации

```json
POST https://api.elevenlabs.io/v1/text-to-speech/<VOICE_ID>?output_format=mp3_44100_128
{ "text": "<кыргызский текст>", "model_id": "eleven_v3",
  "language_code": "ky",
  "voice_settings": { "stability": 0.5, "similarity_boost": 0.75 } }
```

- **Модель — только `eleven_v3`**: единственная с кыргызским (код `ky`, ISO 639-1; в доке листится как Kirghiz/kir). multilingual_v2 и flash/turbo кыргызский НЕ знают.
- **Голоса — реестр `deploy/voices.json`**: у персонажа пол и возраст из сюжета (`characters`, обоснование в `note`), голос — ключ `<пол>_<возраст>`. Возрастная политика: child → голос 18 лет (детские запрещены политикой ElevenLabs), young → 25, adult → 35 (клоны нейтив-спикеров), elder → 65 (Voice Design). Реплики озвучиваются голосом персонажа (поле `sp`), карточки/куплеты — по умолчанию. Новый персонаж/голос = строка в реестре. `KGA1_ROLE=male_child` — прогон одной роли; `KGA1_VOICE` перебивает реестр целиком.
- **Голос — часть контракта, проверять по мете**: любая перегенерация обязана передавать `voice`, иначе сервер возьмёт голос курса по умолчанию и у персонажа сменится пол (наступали дважды, в том числе инструментом аудита). `audit-audio.js` сверяет `_meta.voice` с реестром наравне с поиском обрывов. Это IVC-клон; PVC для кыргызского недоступен (языковой гейт сэмплов + «not optimized for v3»).
- **stability в v3 — три режима**: 0 Creative (галлюцинирует на малоресурсных — не использовать), **0.5 Natural — связная речь** (реплики диалогов, куплеты), **1.0 Robust — карточки-слова** (Natural съедает у них последний согласный, замер: «Атыңыз ким?» 0.66 с без [м] против 0.86 с с [м]). Промежуточные значения недопустимы; правило зашито в `stabilityFor` в gen-audio.js.
- Прод-генерация идёт через серверную ручку `POST /api/tts/<mod>` (ключ на сервере) и батч `deploy/gen-audio.js` (`KGA1_VOICE` обязателен — без него 402/404 молча уводит батч на первый голос аккаунта).

## Железные правила (выучены на браке)

1. **Полные предложения — норма.** v3 стабильнее всего на связной речи; писать фразу целиком с пунктуацией.
1а. **Изолированная кириллическая буква читается ПО-РУССКИ — не отправлять никогда.**
   Самая дорогая ошибка 21.08.2026: дорожки «сам звук буквы» вида «Ө. Ө. Ө.» и
   «Жа. Жо. Жу.» v3 прочитала русской фонетикой (ө как «о», ж как «ж» вместо «дж»),
   потому что вне слова кириллица неотличима от русской. Поймал владелец на слух;
   машинные проверки (полнота повторов, затухание) этого НЕ видят — они отвечают
   на вопрос «звук есть?», а не «звук кыргызский?».
   **Правильная форма — слова курса**: где есть минимальная пара, звук даётся
   контрастом («Кол — көл. Кол — көл.» — русский заменитель против кыргызского;
   выбор владельца из пилота), где пары нет — три слова с этим звуком
   («Жол. Жаңы. Жакшы.», «Эң. Чоң. Миң.»). Пары ищутся перебором словаря курса
   (`deploy/gen-audio.js` → PHONETICS, гейт в `tests/gen-audio.test.js`), не выдумываются.
   Годится и МФА внутри предложения («Бул — /dʒ/. Жа. Жо. Жу.» — тоже одобрено).
1б. **Разделитель внутри запроса — точка, а не запятая**: на запятых v3 читает
   перечисление скороговоркой и глотает элементы («И, и, и.» → 0,65 с и два «и»
   из трёх). Проверка — не на слух: декодировать (`afconvert -f WAVE -d LEI16@44100 -c 1`)
   и посчитать энергетические куски (окна 20 мс, порог 0.2 от пика): их должно быть
   столько, сколько элементов текста. Это уже зашито в `audit-audio.js`.
1в. **Новый рецепт — сперва пилот владельцу, потом набор.** Несколько вариантов
   текста на один звук (`ph_pilot_*`), ссылки на `/api/audio/m0/<id>.mp3`, владелец
   выбирает верный на слух. Пилотные дорожки удалить до ближайшего рестарта —
   при старте все `ph_*` из m0 попадают в публичный демо-набор.
2. **Голый IPA всем текстом — запрещено.** Модель читает его как тарабарщину. IPA — только внутри обычного предложения: `Бул — /yj/.` (паттерн из доки). SSML `<phoneme>` v3 не поддерживает вовсе; словари `.PLS` — только v2.
3. **Числа и символы — прописью** (поле `ky` в курсе и так чистый текст — канон CLAUDE.md).
4. **Короткое слово может вернуть 200 с пустым телом** — сервер сам ретраит на multilingual_v2, которая кыргызского не знает: такие фразы искать в логах по `empty body, retrying with fallback model` и переслушивать.
4а. **Детектор затухания неприменим к дорожкам «сам звук буквы»** (`ph_snd_*`): они
   кончаются гласной или слогом на полной громкости, поэтому хвост/тело у них высокий
   ВСЕГДА — прогон 21.08.2026 дал 7 «обрывов» из 19 при целых файлах. У них свой
   критерий, он уже зашит в `audit-audio.js` (`isSoundTrack`/`wantPieces`/`pieces`):
   звуковых кусков в файле должно быть не меньше, чем элементов текста через точку.
   Лечение засчитывается тем же критерием, каким найден дефект.
   Упорный случай (ө склеивал три повтора в один тянущийся звук) вылечился по общей
   эскалации — Robust на третьей попытке; `KGA1_FIX=1` проходит её сам.
5. **v3 обрезает хвост фразы** — примерно 4% файлов (замер: 6 явных + 12 пограничных из 150 в m0), чаще у коротких карточек. На слух это «не до конца звучит». Детектор — затухание, а не длительность: энергия последних 80 мс к энергии файла (`deploy/audit-audio.js`), >0.5 обрыв, 0.3–0.5 подозрительно. Темп речи обрыв коротких фраз НЕ выдаёт (замер: медиана 14.5 знаков/сек, p90 18, максимум 23.6 — откушенное слово попадает в норму).
6. **Брак лечится по эскалации** (проверено): (а) 1–2 перегенерации в Natural — снимает большинство (17 из 18); (б) **stability 1.0 Robust** — вылечил упорный случай с первой попытки; (в) орфоэпическая перезапись стыков по правилам ассимиляции (см. references); (г) IPA-вставка внутри фразы.
7. **Орфография ≠ орфоэпия.** Нейтив ассимилирует стыки слов («аш болсун» → [аш полсун]); если модель читает «по-письменному» и это слышно — перезаписать текст запроса «как слышится» (отображаемый текст в курсе НЕ меняется). Вычитчик подтвердил: орфоэпическая запись звучит лучше орфографической.
8. **Прежде чем менять текст по жалобе «звучит не так» — проверь обрыв.** В первой же паре вердикт вычитчика был загрязнён усечением: сравнивали орфоэпию с орфографией, а хуже звучал просто обрезанный файл.

## Фонетический минимум (полные правила — references/kyrgyz-phonetics.md)

- 14 гласных: 8 кратких (а э о ө у ү ы и) + 6 долгих (аа оо ээ өө уу үү); долгота фонематична (сат/саат) — долгие в тексте всегда сдвоенной буквой, не «растягивать» иначе.
- Сингармонизм: гласные слова из одного ряда; нарушение в сгенерированном звуке = брак.
- Ударение — на последний слог (кроме отдельных клитик).
- МФА: ү=/y/, ө=/ø/, ы=/ɯ/, а=/ɑ/, ң=/ŋ/, й=/j/, ж=/dʒ/.

## Проектный пайплайн (детали — references/elevenlabs-kyrgyz.md)

- Файлы: `/data/audio/<mod>/<id>.mp3` + `_meta.json` (source: tts|upload|sfx; voice). Реплики диалогов и куплеты (`ph_*`) живут ТОЛЬКО в бакете `m0`.
- Батч: `KGA1_AUTH=… KGA1_VOICE=… [FORCE=1] node deploy/gen-audio.js m0 m1 …`; FORCE никогда не трогает upload (записи преподавателя, песни Suno) и sfx (амбиенты).
- Пилотные/временные дорожки в m0 (`ph_pilot_*` и т.п.) удалять ДО ближайшего рестарта/деплоя — при старте процесса все `ph_*.mp3` из m0 попадают в публичный демо-снимок.
- После смены голоса: обновить `deploy/voices.json` (сервер берёт из него голос курса по умолчанию; env `ELEVEN_VOICE_ID` в Coolify — только как оверрайд), снять залипший оверрайд `DELETE /api/admin/tts-voice` (admin), сверить `GET /api/tts/health`. Фонетика алфавитной карточки (15 ph_* — цели PHONETICS в gen-audio.js) перегенерируется прогоном m0 наравне с остальным.
- Апрувы `audioOk` не сбрасывать; переслушку начинать с диалогов (у них гейта апрува нет).

## Возрастная политика голосов (перенесено из CLAUDE.md 22.08.2026)

Возраст персонажа в данных — правда из сюжета, а озвучивается ближайшим
разрешённым голосом: `child` → голос 18 лет, `young` → 25, `adult` → 35
(клоны живых нейтив-спикеров), `elder` → 65. Синтетические возрасты делаются
**Voice Design** (`/v1/text-to-voice/design`, возраст словами). Детские голоса
ElevenLabs запрещает политикой — блокировку не обходить, только живая запись
с согласием.

## Дорожки урока: цели аудита, но не пакетной генерации

`targetsFor` помечает их `noGen` (текст на языке ученика, а не кыргызский),
поэтому `gen-audio.js` их обходит, а `audit-audio.js` проверяет затухание и
голос наравне с карточками. Без этого 127 файлов урока не проверялись вовсе.
Лечит только `deploy/gen-pronunciation.js` (точечно — `KGA1_ONLY=<регексп по id>`).
